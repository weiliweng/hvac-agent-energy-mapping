# Data Governance

This public repository contains synthetic data only.

## Excluded material

- client or sponsor drawings;
- real BAS point names and tags;
- building names, addresses, or system topology;
- extracted client schedules;
- API keys, endpoints, tokens, and model responses containing private context;
- private human-review workbooks.

## Public-data rule

Every committed record must either be generated by `scripts/generate_synthetic_data.py` or come from a clearly documented public source with a compatible license.

## Model credentials

No credentials are required. Future model integrations must load secrets from environment variables. `.env` files are ignored and must never be committed.
